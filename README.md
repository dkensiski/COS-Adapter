# COS Adapter V2

The Kenwood TK-980 radio's COS output does not go suffciently low to reliably
trigger the Arcom RC210's COS input, so Jim (K6KCP) designed this comparator
circuit to perform the trick. And since I was laying out the board, Steve (W6KCS)
suggested I add some audio adjust circuitry to adjust and filter the audio
between the devices.
